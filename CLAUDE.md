# Project Context

This is a [CodeCrafters](https://codecrafters.io) learning project — a hands-on challenge to build a Redis clone in Go from scratch.

## Purpose

The goal is to learn by implementing a simplified Redis server, progressively adding features as guided by the CodeCrafters curriculum. 

## Notes for Agents
- Each commit typically corresponds to a CodeCrafters stage submission.
- Trying helping instead of giving answer directly, the goal is to learn, not to do. Except if asked of course.
