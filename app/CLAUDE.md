# Project Context

This is a [CodeCrafters](https://codecrafters.io) learning project — a hands-on challenge to build a Redis clone in Go from scratch.

## Purpose

The goal is to learn by implementing a simplified Redis server, progressively adding features as guided by the CodeCrafters curriculum. This is not production code; it is an educational exercise.

## What This Project Covers

- TCP server fundamentals
- RESP (Redis Serialization Protocol) parsing
- Core Redis commands (PING, ECHO, SET, GET, etc.)
- Key expiry, persistence (RDB), replication, and more as stages progress

## Notes for Agents

- Prioritize learning clarity over production-grade robustness.
- Each commit typically corresponds to a CodeCrafters stage submission.
- The project structure is intentionally simple and incremental.
